# Security and release support

Do not open a public issue for a suspected signing, notarization, credential, or artifact integrity
problem. Send the release tag, asset name, observed SHA-256 digest, and non-sensitive reproduction
details to **support@172x.ai**. Never send private keys, tokens, certificates, notarization
credentials, or customer data. Automatic updates are disabled; updater archives and signatures are
not approved release assets.

General download and release support uses the same address. An artifact that fails validation must
remain unavailable while the release owner investigates or selects a prior verified release.
